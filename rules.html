📋 服务器规则

欢迎来到 MC.CN。为了维护良好的游戏环境，请所有玩家遵守以下规则。违规行为将视情节轻重受到警告、禁言、封禁等处罚。

🌐 记住我们的域名

mc.cn 是服务器唯一官方地址，请通过此域名连接。

一、基本行为规范

  • 1. 禁止使用任何严重影响平衡的作弊工具（如杀戮光环、飞行外挂、自动攻击等）。
  • 2. 禁止恶意破坏他人建筑、偷窃物品、破坏公共设施。
  • 3. 禁止在公屏刷屏、辱骂、发布广告、传播色情暴力内容。
  • 4. 禁止利用漏洞卡服、崩服、恶意红石、恶意生物。
  • 5. 尊重管理员和其他玩家，不得冒充管理员或散布谣言。
  • 6. 禁止使用任何形式的透视材质包来获取不正当优势，但允许用于个人观赏，不得影响他人体验。
  • 7. 禁止恶意圈地、占山为王，公共资源区域请共享。
  • 8. 禁止在聊天中透露他人隐私信息。

二、建筑与领地

  • 1. 请在指定区域建造，不要占用公共通道或他人领地。
  • 2. 未经允许不得在他人建筑附近建造，保持合理距离。
  • 3. 不要建造过于庞大且无意义的红石设备，以免影响服务器性能。
  • 4. 禁止建造任何形式的陷阱或恶意机关伤害其他玩家。
  • 5. 公共建筑和设施应共同维护，不得破坏。

三、聊天与交流

  • 1. 请使用文明语言，避免争吵。
  • 2. 禁止刷屏、重复发送相同信息。
  • 3. 禁止发布任何广告或宣传其他服务器。
  • 4. 禁止讨论政治、宗教等敏感话题。
  • 5. 禁止恶意举报或滥用举报系统。

四、红石与性能

  • 1. 大型红石机器请控制规模，避免造成服务器卡顿。
  • 2. 禁止建造高频红石脉冲或永动装置。
  • 3. 自动化设备应设置合理的开关，避免长期满载运行。
  • 4. 服务器管理员有权对影响性能的装置进行限制或拆除。

五、作弊与漏洞

  • 1. 禁止使用任何修改客户端、注入式外挂、宏脚本等。
  • 2. 发现漏洞请立即向管理员报告，不得利用漏洞获利。
  • 3. 禁止使用任何形式的复制物品漏洞。
  • 4. 禁止恶意卡服、崩服、DDoS 攻击。

六、交易与物品

  • 1. 禁止诈骗、强买强卖。
  • 2. 交易请使用安全方式，谨防上当。
  • 3. 禁止出售或购买游戏账号、物品（RMT），一经发现永久封禁。

七、违规处理

  • 1. 轻微违规：警告一次。
  • 2. 再次违规：禁言 1~7 天。
  • 3. 严重违规：封禁 7 天至永久。
  • 4. 对处罚有异议可联系管理员申诉。

本规则最终解释权归 MC.CN 服务器管理组所有。感谢配合！
