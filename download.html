下载服务

本栏目提供 MC.CN 官方 ATM10 客户端整合包下载渠道和安装使用说明。请通过官方渠道下载，避免使用来源不明的文件。

ATM10 客户端整合包

前往 CurseForge 官方页面下载整合包，不占用本中心服务器带宽。

前往 CurseForge 下载

安装说明

  1. 在 CurseForge 页面点击“Download”下载整合包压缩文件（通常为 .zip）。
  2. 解压到任意目录（推荐使用 7-Zip 或 WinRAR）。
  3. 使用 MultiMC、Prism Launcher 等启动器导入该实例。
  4. 在启动器中选择 Java 21，内存分配建议 4~8GB。
  5. 启动游戏，在多人游戏服务器地址输入 mc.cn 加入服务器。

注意事项

  • 请从本页面提供的官方链接下载，不要使用第三方修改包。
  • 如遇下载或安装问题，可通过官方渠道反馈。
  • 使用本服务即表示同意遵守《MC.CN 网络信息服务中心规章制度》。
