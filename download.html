二、安装说明

  1. 在 CurseForge 页面点击“Download”下载整合包压缩文件（通常为 .zip）。
  2. 解压到任意目录（推荐使用 7-Zip 或 WinRAR）。
  3. 使用 MultiMC、Prism Launcher 等启动器导入该实例。
  4. 在启动器中选择 Java 21，内存分配建议 4~8GB。
  5. 启动游戏，在多人游戏服务器地址输入 mc.cn 加入服务器。

四、常见问题

  • 下载速度慢怎么办？可尝试更换网络环境或使用下载加速工具。
  • 启动报错 Java 版本不对？请安装 Java 21 并确保启动器选择正确。
  • 内存不足？建议将启动器内存分配调整为 4~8GB，并关闭其他大型程序。
  • 无法连接服务器？请确认服务器地址为 mc.cn，并检查网络设置。
  • 客户端文件被安全软件拦截？请从官方渠道下载并核对文件来源。
