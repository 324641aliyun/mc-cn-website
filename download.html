安装说明

  1. 在 CurseForge 页面点击“Download”下载整合包压缩文件（通常为 .zip）。
  2. 解压到任意目录（推荐使用 7-Zip 或 WinRAR）。
  3. 打开解压后的文件夹，找到启动器（如 MultiMC 或 Prism Launcher 的实例文件夹）。
  4. 将实例导入启动器，或直接运行启动器选择该实例。
  5. 在启动器中选择 Java 版本为 Java 21，内存分配 4~8GB。
  6. 启动游戏，在多人游戏服务器地址输入 mc.cn，加入服务器。

如遇问题，请检查网络或重新下载。也可以在游戏内反馈。
